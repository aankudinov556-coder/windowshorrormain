# AFTER SIGN-OFF

*Analog horror, замаскированный под старую операционную систему.*

Игрок работает техником в компьютерной мастерской. Ему поручили снять файлы со старого ПК, который 23 года пролежал в кладовке. Это компьютер Дэниела Мерсера, ночного инженера передатчика маленького телеканала **Channel 12**. Дэниел пропал в октябре 2003-го. Сначала это просто старая система «в духе XP»: обои с холмом, почта, фотографии. Потом в бэкапе появляется файл, которого раньше не было, часы показывают 3:33, а на обоях у телевышки кто-то стоит.

> 🇬🇧 *An analog horror game disguised as a fictional 2002 operating system. Back up a dead man's PC — and find out what was broadcasting from his tower at 3:33 AM.*

ОС **Meridian 2002** вымышленная: свой логотип, свои названия, все иконки, звуки и изображения оригинальные и генерируются процедурно.

**Языки:** English, Русский. Язык выбирается на первом экране или в BIOS Setup (**DEL** при загрузке), а при первом запуске определяется по языку системы. Как добавить новый язык или свои ассеты (звуки, озвучку, картинки), описано в [docs/LOCALIZATION.md](docs/LOCALIZATION.md).

## Как запустить из исходников

### Быстро, в браузере
Открыть `src/index.html` в Chrome/Edge (двойным кликом) или поднять локальный сервер:

```bash
npm run serve
```

Затем открыть http://localhost:8080.

### Как настоящее приложение (Electron, полный экран)
Нужен [Node.js](https://nodejs.org) 18+.

```bash
npm install
```

```bash
npm start
```

`npm run dev` запускает в окне (не на весь экран) и разрешает DevTools на F12. **F11** переключает полноэкранный режим.

### Сборка Windows `.exe`
Запускать на Windows:

```bash
npm install
```

```bash
npm run dist
```

В папке `dist/` появятся установщик (NSIS) и портативный `Meridian-portable.exe`.

## Управление и настройки
- Всё мышью, как в настоящей ОС: двойной клик открывает, правый клик вызывает контекстное меню.
- **DEL** на экране BIOS открывает Setup: язык, режим «меньше вспышек», громкость, полноэкранный режим, **новая игра**, полный сброс.
- Прогресс сохраняется автоматически (localStorage). Если закрыть игру, она продолжится с того же места.

### Параметры для отладки (в браузере)
| Параметр | Что делает |
|---|---|
| `?skip=1` | сразу рабочий стол, без BIOS и входа |
| `?level=0..4` | начать с уровня заражения |
| `?reset=1` | стереть сохранение |
| `?user=Имя` | подставить имя игрока (в Electron берётся имя пользователя Windows) |
| `?lang=ru` | выбрать язык (`en`, `ru`, …) |
| `?i18ndebug=1` | писать в консоль ключи, которых нет в переводе |

Пример: `index.html?skip=1&level=3&user=Andrey`. В консоли доступны `G.debug.level(n)`, `G.debug.end('bad'|'good')` и `G.debug.missing()`.

Проверка переводов:

```bash
npm run i18n:check
```

## Структура проекта

```
electron/            оболочка Electron (main + preload)
src/
  index.html         точка входа
  lang/              языковые пакеты: languages.js + en/ ru/ (ui, content, story)
  assets/manifest.js слоты под записанные звуки (заменяют синтез)
  css/               os.css (оболочка ОС), apps.css (приложения), fx.css (хоррор-эффекты)
  js/core/           util, i18n (локализация), state (сохранения), audio (синтез звука), fx (глитчи), cursor
  js/os/             иконки, файловая система, оконный менеджер, диалоги, обои, рабочий стол, панель задач, загрузка
  js/content/        дерево файлов, структура почты, VHS-записи (тексты — в lang/)
  js/apps/           Проводник, Блокнот, фото, почта, Meridian TV, cmd + txctl, Диспетчер задач, бэкап, мелочи
  js/story/          director.js (сюжет, уровни, скримеры), endings.js
  assets/img/        сгенерированные «фотографии»
assets_src/          исходные картинки + slots.json (кадрирование, цвет, наложения) + credits.json
tools/gen_photos.py  конвейер картинок: исходники/процедурные → «мыльница 2003» (Python + Pillow + numpy)
tools/export_voice.js  выгрузка сценария озвучки в CSV (npm run voice:export)
tools/check_i18n.js  проверка полноты и корректности переводов
docs/PLAN.md         дизайн-документ, лор, прохождение (спойлеры!)
```

Ассеты:
- **фото** — реальные снимки CC0 и в общественном достоянии с Wikimedia Commons, обработанные под «мыльницу 2003 года» с сюжетными добавлениями; часть кадров нарисована кодом. Пересобираются командой `npm run photos`;
- **VHS-записи** рисуются на canvas поверх реальных фонов (дом, комната, вышка) с VHS-эффектами;
- **звук** синтезируется в реальном времени через WebAudio, голоса идут через системный TTS.

Как заменить любой ассет своим (ИИ-картинки, записанные звуки, озвучка) и промпты для генерации — в [docs/ASSETS.md](docs/ASSETS.md). Источники и лицензии перечислены в [docs/CREDITS.md](docs/CREDITS.md).

Полный дизайн, лор и прохождение лежат в [docs/PLAN.md](docs/PLAN.md) (там спойлеры).
