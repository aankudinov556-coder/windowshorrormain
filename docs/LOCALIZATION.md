# Локализация и ассеты

Весь текст игры лежит в **языковых пакетах**, код только запрашивает строки по ключу. Сейчас есть два языка: **English** (эталон) и **Русский**.

## Как устроено

```
src/lang/
  languages.js        список языков (код, название, голос TTS, файлы, свои ассеты)
  en/ui.js            интерфейс ОС: меню, окна, ошибки, приложения
  en/content.js       документы Дэниела, письма, контакты
  en/story.js         VHS-записи, реплики Ведущего, txctl, концовки
  ru/...              те же файлы, те же ключи
```

- Код вызывает `G.t('ключ', {переменные})`.
- **Английский — запасной язык.** Если в переводе нет ключа, игра покажет английский текст, а не сломается.
- Значение может быть строкой, **списком** (`['строка 1', 'строка 2']` — карточки, пулы случайных фраз) или **функцией** `(state) => '...'` (текст, зависящий от прогресса).
- Плейсхолдеры:
  - `{name}`, `{n}`, `{v}` подставляет код, их нужно сохранить в переводе;
  - `{USER}` / `{User}` / `{user}` — имя игрока (капсом / с заглавной / строчными);
  - `{TIME}`, `{DATE}` — текущие время и дата.
- Форматы задаются в самом пакете:
  - `fmt.clock`: `'12'` (3:33 AM) или `'24'` (3:33);
  - `fmt.date`: `'mdy'` (10/14/2003) или `'dmy'` (14.10.2003);
  - `unit.*`: единицы и десятичный разделитель.
- Язык выбирается на первом экране игры или в BIOS Setup (клавиша **DEL** при загрузке). При первом запуске он определяется по языку системы. Для отладки есть параметр `?lang=ru`.

## Как добавить новый язык (например, немецкий)

1. Скопировать папку `src/lang/en` в `src/lang/de`.
2. В каждом файле заменить `G.i18n.add('en', {` на `G.i18n.add('de', {` и перевести значения. **Ключи не трогать.**
3. Добавить язык в `src/lang/languages.js`:
   ```js
   { code: 'de', native: 'Deutsch', speech: 'de', files: ['ui.js', 'content.js', 'story.js'], assets: [], voices: {} }
   ```
4. Проверить перевод:
   ```bash
   npm run i18n:check
   ```
   Скрипт покажет процент перевода, недостающие ключи (они временно останутся на английском), опечатки в ключах, потерянные `{плейсхолдеры}` и места, где вместо списка оказалась строка.
5. Запустить игру с `?lang=de` или выбрать язык на первом экране.

**Советы переводчику:**
- **Пароль головоломки — `20525`**, это цифры частоты 205.25 MHz. В переводе частоту можно писать с запятой (`205,25 МГц`), игра примет любой вариант.
- **Команды `txctl ...` не переводятся**, это команды программы. Переводятся только описания в `cmd.txhelp` и `doc.txctl`.
- **Пути к файлам в текстах** должны совпадать с переведёнными именами папок и файлов (`fs.*`, `file.*`).
- **Имя Ведущего** (`name.host`) и то, что он вписывает в журнал (`tx.hostPretype`), лучше делать одним словом, на этом построена финальная сцена.
- **Обращения к игроку лучше писать без указания рода**: пол игрока неизвестен.
- **Строки в кадре записей** (`tp.*`) автоматически уменьшаются, если не влезают в ширину кадра. Короче всё равно лучше.

## Ассеты

Сейчас игре не нужны внешние файлы: звук синтезируется, картинки генерирует `tools/gen_photos.py`. Под будущие ассеты подготовлены «слоты».

### Записанные звуки вместо синтеза — `src/assets/manifest.js`
```js
G.ASSETS = {
  sounds: {
    startup: 'sfx/startup.ogg',   // файл src/assets/sfx/startup.ogg
    scare:   'sfx/scare.ogg'
  }
};
```
Имена звуков: `startup, shutdown, logon, ding, exclaim, notify, click, type, hdd, hddDeath, static, staticShort, glitch, scare, sting, thump, heartbeat, whisper, jingle, blip`. Если файл не загрузится, сработает синтезированная версия.

### Картинки
Все фото берутся из `src/assets/img/`. Их можно заменить на новые с тем же именем, например настоящими фотографиями CC0 или артом.

### Свои ассеты для языка
Если картинка содержит текст (вывеска, записка) и её нужно перевести:
1. Положить файл в `src/lang/<код>/assets/img/<имя>.jpg`.
2. В `languages.js` добавить путь в `assets`, например `assets: ['img/school_play_2003.jpg']`.

Так же работает для звуков: `assets: ['sfx/jingle.ogg']`.

### Озвучка реплик
Сейчас реплики в записях читает системный синтезатор речи. Для языка, у которого на ПК нет голоса, остаются только субтитры. Записанная озвучка подключается по ключу строки:
```js
voices: {
  'tp.h.say':  'host_good_evening.ogg',   // файл src/lang/<код>/assets/voice/host_good_evening.ogg
  'tp.e.say1': 'eas_guests.ogg'
}
```
Ключи реплик: `tp.s.say`, `tp.r.say1`, `tp.r.say2`, `tp.h.say`, `tp.e.say1`, `tp.e.say2`, `tp.o.say`, `tp.i.say`, `tp.l.sayEvening`, `tp.l.sayDont`, `end.h.say`.
